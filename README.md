# pracitc3

## Практика 3: Аутентификация, права доступа и статика

- **Разделила пользователей по ролям:** создала свою модель User и связала её связью «один к одному» с профилями Student и Teacher. Добавила свойства is_student и is_teacher, чтобы быстро определять роль.
- **Настроила вход и выход:** подключила стандартные страницы авторизации (LoginView) и выхода (LogoutView), сделала шаблон входа с защитой полем next для возврата на закрытые страницы.
- **Ограничила доступ к страницам:** закрыла кабинеты декоратором @login_required и проверками ролей. Если роли не совпадают, показывается отказ в доступе.
- **Сделала функцию-диспетчер profile_dispatch:** перенаправляет пользователя после входа в зависимости от роли (студента к расписанию/кабинету, преподавателя — к журналу).
- **Подключила статические файлы:** создала папки для статики с изоляцией по имени приложения (attendance/static/attendance/), добавила свой style.css и логотип-заглушку. Подключила их через шаблонный тег {% static %}.
- **Добавила Bootstrap 5:** подключила CSS и JS библиотеки Bootstrap через CDN. Оформила страницы и добавила адаптивную кнопку-меню («гамбургер») для мобильных экранов.

## Практика 4: Загрузка файлов и GET-фильтрация

- **Настроила работу с файлами (MEDIA):** прописала параметры MEDIA_URL и MEDIA_ROOT в settings.py и настроила раздачу медиафайлов в urls.py при включённом режиме разработки.
- **Сделала ручную загрузку файлов:** написала форму с enctype="multipart/form-data" и обработчик, который читает файл частями через chunks() и сохраняет его на диск с уникальным именем через UUID, чтобы файлы с одинаковым названием не затирали друг друга.

- **Добавила загрузку аватарок студентам:** в модель Student добавила поле ImageField с функцией upload_to, раскладывающей файлы по папкам с датами и уникальными ID.
- **Ограничила загрузку и очистили старые файлы:** в форме StudentAvatarForm настроила серверную проверку (только форматы JPEG/PNG и вес не более 5 МБ). Добавила Django-сигналы, которые автоматически удаляют старое изображение с диска при загрузке нового. Доступ к смене аватара дали только авторизованному студенту.
- **Реализовали фильтр списка студентов через GET-запрос:** создала форму StudentFilterForm, которая считывает параметры из адресной строки (request.GET). Настроила поиск по части фамилии, выбор группы из базы (ModelChoiceField) и поиск по части названия группы с помощью ORM-фильтра icontains. Значения фильтров сохраняются в полях формы после отправки.
